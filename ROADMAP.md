# Roadmap - ArcadeKeep

Evolución planificada para la gestión integral de colecciones retro.

## Fase 1: Mejoras de Inventario (Próximo)
- [ ] Soporte para lector de código de barras físico USB / Bluetooth (modo emulación teclado/HID).
- [ ] Filtros avanzados por estado del artículo (CIB, Loose, Boxed, Sealed).
- [ ] Desglose por accesorios específicos y componentes (cables, manuales, transformadores).

## Fase 2: Valoración y Finanzas
- [ ] Conversión automática de divisas (USD a EUR) con tipos de cambio actualizados.
- [ ] Gráficas de evolución histórica del valor de la colección en el tiempo.
- [ ] Alertas de revalorización en títulos clave.

## Fase 3: Respaldo y Sincronización
- [ ] Backup programado diario de SQLite hacia Proxmox Backup Server / NAS.
- [ ] Exportación completa de catálogo en formatos CSV, JSON y PDF imprimible.
- [ ] Modo offline enriquecido con sincronización bidireccional PWA.
