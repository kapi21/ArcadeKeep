# ArcadeKeep

**ArcadeKeep** es una aplicación web progresiva (PWA) para catalogar, gestionar y valorar colecciones de videojuegos retro, consolas y accesorios.

## Características

- 📷 **Escaneo móvil**: Lector de códigos de barras integrado mediante cámara.
- 💰 **Valoración automática**: Cotizaciones de mercado en tiempo real a través de PriceCharting.
- 📱 **Experiencia PWA**: Interfaz adaptada a dispositivos móviles e instalable en pantalla de inicio.
- 🗄️ **Base de datos local**: Motor SQLite integrado sin dependencias externas pesadas.
- 🚀 **Despliegue Proxmox LXC**: Preparado para funcionar en red local o servidor doméstico.
